# 抑郁障碍

| **考点分类**                              | **诊断核心与评估**                                                                   | **一线治疗与临床管理**                                                                   |                                                                                                 |
| ------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **抑郁症** MDD Major Depression disorder | 核心症状加上其他症状共 5 项以上 (SIGECAPS)，持续至少 2 周；必须造成临床显著的功能损害；必须排除既往有躁狂 Manic 发作以排除双相障碍 | 需排除由物质滥用或躯体疾病引起的症状；不推荐常规使用生物标志物检测或药物基因组学测试                                      | 哀恸延长障碍 Prolonged Grief Disorder 需持续至少 12 个月; 持续性抑郁障碍 Persistent Depressive Disorder 症状需持续至少 2 年 |
| **首选药物**                              | 包含SSRIs，SNRIs，以及安非他酮 Bupropion                                                | 治疗 2-4 周无早期改善应增加剂量，若有改善则继续当前治疗 6-8 周；疗效不佳时可考虑换药或添加辅助 Adjunctive 药物              | 安非他酮不会导致体重增加且性功能障碍风险最低; 西酞普兰 Citalopram 剂量不可超过 40mg                                             |
| **副作用管理**                             | 常见副作用包括胃肠道恶心、失眠或嗜睡、性功能障碍和体重增加                                                 | 恶心可随餐服用或等待耐受；性功能障碍可尝试减量，或添加安非他酮、西地那非 (Sildenafil) 等                             | Serotonin Syndrome 表现为寒战、反射亢进、发热和脑病 (Encephalopathy)                                            |
| **非药物干预** (Non-Pharm Tx)              | 认知行为疗法 (CBT) 重点改变负面核心信念的三联征；人际关系疗法 (IPT) 关注角色转换、悲伤、人际冲突等焦点。                   | 针对轻度季节性抑郁推荐光疗 (Light therapy) 作为一线单药治疗；轻度抑郁可推荐有氧加抗阻的监督下运动 (Supervised exercise) | 电休克疗法 (ECT) 是一线用于伴精神病性特征、严重自杀倾向或紧张症 (Catatonia) 的急救方案；重复经颅磁刺激 (rTMS) 适用于难治性抑郁症                  |
| **围产期抑郁** (Perinatal MDD)             | 孕期未治疗的抑郁症会增加早产、低出生体重以及母亲物质滥用的风险；既往对某种药物反应良好，则通常优先继续使用该药。                      | 舍曲林 (Sertraline) 是孕期及哺乳期首选的 SSRI; 中重度抑郁推荐药物治疗或心理治疗，Zuranolone 可用于快速治疗产后抑郁       | 孕晚期暴露于 SSRIs 可能导致新生儿短暂的不良适应综合征 (PNAS)，但不建议在分娩前停药以免复发；绝对不建议单用心理治疗应对重度围产期抑郁                       |
| 老年抑郁                                  | Pseudodementia 老年患者常以严重的记忆力减退和认知障碍就诊，容易被误诊为痴呆 Dementia                        | 抑郁性假性痴呆患者；因为抑郁所以表现出类似痴呆症状-如健忘，但核心在于知道自己忘了                                       | 通常在认知测试中表现出“不知道”的消极态度，而真正的痴呆患者往往会试图掩盖自己的记忆缺陷。治疗抑郁后，认知功能常可恢复。                                    |

| **发生时间**：通常在停药、漏服或减量后的 1-3 天内迅速出现 **病程特点**：若不进行干预，症状通常在 1-2 周内自行缓解，通常无严重后遗症 | 经典助记词 **FINISH**：**F**lu-like symptoms (流感样症状，如乏力、肌肉酸痛) **I**nsomnia (失眠) **N**ausea (恶心及胃肠道反应)  **I**mbalance (平衡障碍或头晕) **S**ensory disturbances (感觉异常，极具特征性) **H**yperarousal (过度觉醒，如焦虑、易激惹) | **最高危药物**：半衰期极短且无活性代谢产物的药物。绝对高频考点为帕罗西汀 (Paroxetine) 和文拉法辛 (Venlafaxine) **最低危药物**：半衰期最长的药物，如氟西汀 (Fluoxetine)，因其具有自身逐渐减量的代谢效应，极少引起此综合征 |

| **药策略**                                                                                                   | **适应证条件**：                                           |                                                                                                                 |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **一线选择**：舍曲林 (Sertraline)、安非他酮 (Bupropion)、米氮平 (Mirtazapine)  **二线选择**：三环类抗抑郁药 (TCAs)、单胺氧化酶抑制剂 (MAOIs)    | 1. 首次抗抑郁药物尝试治疗失败2. 患者对原药物的副作用完全不可耐受 3. 患者当前抑郁症状程度不严重 | **优先原则**：通常优先选择换用另一种抗抑郁药 (AD)，而非立即加用抗精神病药 (AP) **临床考虑**：若首次 SSRI 无效，可换用同类另一种 SSRI 或换用不同机制的药物 (如 SNRI/Bupropion) |
| **一线加药**：阿立哌唑 (Aripiprazole)（抗精神病药）; **二线加药**：安非他酮 (Bupropion)（副作用少）、米氮平 (Mirtazapine)、艾司氯胺酮 (Esketamine) | 1. 原药物有部分疗效，但未达临床缓解2. 症状较为严重 3. 新加药物的副作用可以被目标化利用     | **靶向副作用机制**：例如原药物导致失眠，可加用米氮平 (Mirtazapine) 利用其镇静作用；若原药物导致性功能障碍，可加用安非他酮 (Bupropion) 进行对抗                         |

- 在开具任何抗抑郁药之前，**必须**主动筛查是否有轻躁狂/躁狂病史；单用抗抑郁药可能诱发双相患者的躁狂发作 Manic ；换药/加药优先选 AD（抗抑郁药）而非 AP（抗精神病药）
- **躯体疾病排除 (VITAMINS-D Rule):** 遇到老年首发抑郁或伴随非典型躯体症状的患者，优先排除甲状腺功能减退，查 TSH、贫血、维生素 B12 缺乏，以及药物性抑郁 (如类固醇、酒精)
- **伴躯体疼痛** 优先选择度洛西汀 (Duloxetine) 等 SNRIs，对纤维肌痛和神经病理性疼痛有额外疗效
- **伴严重失眠/极度消瘦** 优先选择米氮平 (Mirtazapine)，利用其增加食欲和镇静的副作用
- **伴精神病性特征** 单用抗抑郁药无效。**必须**使用抗抑郁药联合抗精神病药 (AD + AP)，或直接使用 ECT
- **依从性差/容易漏服药:** 优先选择氟西汀 (Fluoxetine)，因为其半衰期最长，突然停药引发停药综合征的风险极低

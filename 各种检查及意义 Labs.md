#### 肝脏检查

| **指标 (Index)**                                               | **参考范围**                                             | **临床意义 / 说明 (Clinical Significance / Description)** |
| ------------------------------------------------------------ | ---------------------------------------------------- | --------------------------------------------------- |
| **总蛋白 (Total Protein, TP)**                                  | $60 \sim 80\text{ g/L}$                              | 由于 $\gamma$-球蛋白由浆细胞合成，其余蛋白由肝脏合成，故可用来反映二者的代谢情况       |
| **清蛋白 (Albumin, Alb)**                                       | $40 \sim 55\text{ g/L}$                              | 由于 $\gamma$-球蛋白由浆细胞合成，其余蛋白由肝脏合成，故可用来反映二者的代谢情况       |
| **球蛋白 (Globulin, Glb)**                                      | $20 \sim 30\text{ g/L}$                              | 由于 $\gamma$-球蛋白由浆细胞合成，其余蛋白由肝脏合成，故可用来反映二者的代谢情况       |
| **白球比 (Albumin/Globulin Ratio, A/G)**                        | $(1.5 \sim 2.5) / 1$                                 | 由于 $\gamma$-球蛋白由浆细胞合成，其余蛋白由肝脏合成，故可用来反映二者的代谢情况       |
| **总胆红素 (Total Bilirubin, STB/TBil)**                         | $3.4 \sim 17.1\text{ }\mu\text{mol/L}$               | 用于确立黄疸诊断及病因分类                                       |
| **结合胆红素 (Conjugated Bilirubin, CB/DBiL)**                    | $0 \sim 6.8\text{ }\mu\text{mol/L}$                  | 用于确立黄疸诊断及病因分类                                       |
| **未结合胆红素 (Unconjugated Bilirubin, UCB/IBiL)**                | $1.7 \sim 10.2\text{ }\mu\text{mol/L}$               | 用于确立黄疸诊断及病因分类                                       |
| **转氨酶 (Transaminases)**<br>丙氨酸氨基转移酶 (ALT)<br>天冬氨酸氨基转移酶 (AST) | - $5 \sim 40\text{ U/L}$<br>- $8 \sim 40\text{ U/L}$ | 判断肝脏损伤程度；其中 AST 大部分在线粒体中，故 AST 升高反映更加严重的肝细胞损伤       |

| CO弥散率 (DLCO)         | 男性：18.23～38.41 ml/(mmHg×min)<br>女性：20.85～23.9 ml/(mmHg×min) | 反映氧气弥散功能                                                                  |

| 动脉二氧化碳分压 (PaCO2)     | 35～45 mmHg                                                  | >45 mmHg提示呼吸性酸中毒；<35 mmHg提示呼吸性碱中毒；I型呼衰可降低；II型呼衰需>50 mmHg；肺性脑病时一般应>70 mmHg |
| pH值                  | 7.35～7.45                                                   | <7.35为失代偿性酸中毒；>7.45为失代偿性碱中毒；特别注意：不能单用pH区分子代谢与呼吸性酸碱失衡，还需结合其他指标判断           |

| 剩余碱 (BE)             | $\pm$ 2.3 mmol/L                                            | 代谢性酸中毒：减小；代谢性碱中毒：增大                                                       |
| 阴离子间隙 (AG)           | 8～16 mmol/L                                                 | 计算公式：AG=Na+-(Cl-+HCO3-)<br>高AG酸中毒常见于：尿毒症、DKA、乳酸酸中毒<br>正常AG见于：肾小管中毒、腹泻     |
| 呼吸频率                 | 12～20 次/分                                                   | 浅快：呼吸肌麻痹、胸腔积液、气胸等<br>深快：代谢性酸中毒、剧烈运动等                                      |
| 氧合指数 (PaO2/FiO2)     | 400～500 mmHg                                                | ≤300 mmHg是诊断ARDS的必要条件                                                     |
